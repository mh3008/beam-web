# Beam web

A web app for JBL Live Beam 4 earbuds and their touchscreen case: battery for each bud and the case, battery history, and case screen controls. Open the page, tap **Connect to my buds**, and choose the buds in your browser's Bluetooth list.

- Needs Web Bluetooth: Chrome or Edge on a PC or Android phone, or the **Bluefy** browser on an iPhone (Safari doesn't have it).
- Add `?demo=1` to the address to try it with fake buds, no Bluetooth needed. `?demo=wear` shows both buds in use.
- Battery history and settings stay in your browser. Nothing is sent anywhere.
- It only writes the case brightness, the clock, find-my-case and the quick-access order. It never sends firmware, update, reset or power-off commands.
