    Made by Morgan Harris

    A web app for JBL Live Beam 4 earbuds and their touchscreen case. It shows the battery of each bud and the case, and controls the case screen, without JBL's phone app.

    Not affiliated with JBL or Harman. It never sends firmware, update, reset or power-off commands.

    How it was worked out

    The buds speak a private language

    JBL doesn't publish how the Live Beam 4 talks over Bluetooth. Other JBL earbuds use one dialect, but this model ignored it completely.

    Protocol 4, and a two-byte header

    The Beam 4 uses a newer dialect called Protocol 4. Every message starts with the two bytes 00 DD, then says what it wants (read, set, or news) and which feature. Use a slightly wrong header and the buds simply hang up.

    Asking, then decoding

    Beam asks things like "what's your battery?" and "set the case brightness to 40", and decodes the answers: which byte is the percentage, which bit means charging. Each control was checked by reading the value back.

    Still to crack

    Switching noise cancelling, and putting your own picture on the case screen. The buds accept those messages but nothing changes yet, so they stay off until the real format is captured from JBL's app.
